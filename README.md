## Preview

Modern dark theme with:
- Voucher & Member login mode
- Package pricing display
- Session status page
- CHAP authentication support

## Files

| File | Description |
|------|-------------|
| login.html | Main login page |
| alogin.html | Redirect after login |
| success.html | Login success page |
| error.html | Error page |
| status.html | Session status |
| logout.html | Logout page |
| radvert.html | Redirect page |
| rlogin.html | Session expired |
| md5.js | MD5 for CHAP auth |
| errors.txt | Error messages (ID) |
| errors-en.txt | Error messages (EN) |

## Installation

1. Download all files
2. Upload to MikroTik via Files
3. Set HTML directory in Hotspot Server Profile
